# Water Meter Card

Карточка Home Assistant для отображения показаний счётчиков горячей и холодной воды.

## Установка

Выберите способ, который соответствует интерфейсу Home Assistant.

### Через Marketplace

1. Откройте **Настройки → Marketplace**.
2. Выберите **Добавить по ссылке на GitHub**.
3. Вставьте ссылку на репозиторий: [https://github.com/MaximSN/ha-water-meter-card](https://github.com/MaximSN/ha-water-meter-card)
4. Откройте добавленный репозиторий и нажмите **Установить**.

### Через HACS

1. Откройте **HACS**.
2. Откройте меню дополнительных репозиториев.
3. Добавьте ссылку https://github.com/MaximSN/ha-water-meter-card и выберите категорию **Dashboard**.
4. Найдите **Water Meter Card** и установите карточку.
5. Обновите страницу Home Assistant.

## Добавление карточки

1. Откройте нужную панель управления.
2. Перейдите в режим редактирования и нажмите **Добавить карточку**.
3. Найдите и выберите **Water Meter Card**.
4. В визуальном редакторе выберите сенсоры показаний и корректировок.
5. При необходимости укажите название помещения, номера счётчиков, цвета и шаг корректировки.
6. Сохраните карточку.

## Использование

Кнопки «−» и «+» изменяют корректировку соответствующего счётчика. Кнопка сохранения открывает окно проверки показаний. После подтверждения карточка отправляет значения в счётчики. Корректировка каждого счётчика сбрасывается только после подтверждения успешной записи.
