# Water Meter Card

Кастомная карточка Home Assistant для двухканального счётчика воды. Позволяет отображать итоговые показания ГВС и ХВС, изменять софт-корректировки и вручную фиксировать итоговые значения в приборе.

## Что подготовить

Перед добавлением карточки создайте в Home Assistant:

- два шаблонных сенсора итоговых показаний — ГВС и ХВС;
- два помощника `input_number` для софт-корректировок — отдельно для ГВС и ХВС;
- две сущности `number` прибора для записи показаний: канал L3 (ГВС) и канал L5 (ХВС).

Шаблонные сенсоры должны уже учитывать соответствующие `input_number`. Карточка отображает именно итоговые шаблонные сенсоры.

## Установка через HACS

1. Откройте HACS в Home Assistant.
2. Перейдите в меню дополнительных репозиториев.
3. Добавьте `https://github.com/MaximSN/ha-water-meter-card` как репозиторий типа **Dashboard**.
4. Найдите **Water Meter Card** и установите.
5. Обновите ресурсы интерфейса Home Assistant.

## Ручная установка

1. Скопируйте файл `ha-water-meter-card.js` в каталог `/config/www/`.
2. В Home Assistant откройте **Настройки → Панели управления → Ресурсы**.
3. Добавьте ресурс `/local/ha-water-meter-card.js` с типом **JavaScript Module**.
4. Обновите страницу Home Assistant.

## Добавление и настройка карточки

1. Откройте нужную панель управления и выберите **Добавить карточку**.
2. Найдите **Water Meter Card**.
3. В визуальном редакторе выберите сенсоры итоговых показаний, помощники корректировок, сущности записи L3/L5 и при необходимости сенсоры батареи и сигнала.
4. Укажите название помещения, номера счётчиков, цвета и шаг корректировки.

Кнопки «−» и «+» изменяют только соответствующий помощник `input_number`. Иконка сохранения открывает окно фиксации. После подтверждения карточка отправляет оба итоговых значения в прибор и ждёт обновления сущностей. Поправка каждого канала обнуляется только после подтверждения записи этого канала.

## Как выглядит карточка

Скриншоты карточки, окна фиксации показаний и визуального редактора будут добавлены после проверки интерфейса в Home Assistant.
